Finalidad y estado de la aplicación

Trend investiga temas y señales de interés en publicaciones públicas para apoyar la planificación de contenido original. La conexión del operador permite consultar las API autorizadas de Meta. El objetivo son publicaciones públicas de otras páginas y creadores, dentro del acceso permitido por la plataforma. La aplicación está en preparación: existen pruebas de lectura pública en Instagram; el acceso público de Facebook y el consolidado semanal multirred siguen pendientes.

Datos recogidos

En Instagram se guardan identificadores, texto disponible, enlaces públicos, tipo de publicación, hashtag consultado, fecha de observación y conteos disponibles de me gusta y comentarios. El lector preparado para Facebook solicita identificador, texto, enlace y conteos agregados de reacciones y comentarios. Los datos ausentes se conservan como desconocidos. El texto público puede contener información personal publicada por su autor.

Los lectores actuales no recogen mensajes privados, listas de contactos, contraseñas, datos bancarios ni nombres o textos de quienes comentan. No descargan archivos de imágenes o videos. La autorización de una API no implica autorización para reutilizar contenido ajeno.

Almacenamiento y acceso

Las observaciones actuales se guardan en informes y una base de investigación en la laptop del operador. La credencial de Meta se guarda separadamente en el Administrador de credenciales de Windows y no se incluye en los informes. El operador y las herramientas internas autorizadas usan los registros para investigación y planificación. La integración prevista con el área interna de Monetización todavía no está certificada.

Esta página pública contiene únicamente documentación de privacidad e instrucciones de eliminación; no contiene la base de investigación, el código operativo ni credenciales. El uso futuro de servicios externos de análisis o cambios en los destinatarios requerirá revisar esta política antes de ponerlos en operación.

Conservación y solicitudes

En esta etapa los registros son acumulativos y no hay un plazo fijo ni eliminación automática programada. La conservación y eliminación se gestionan manualmente por el responsable. Puede solicitar información sobre sus datos o su eliminación mediante el correo de contacto. La revisión debe abarcar la base de investigación, informes y copias que contengan el registro. Si un registro debe conservarse por una obligación aplicable, se explicará la limitación al solicitante.

Las instrucciones para identificar los registros y presentar una solicitud están en la página de eliminación. No envíe contraseñas, tokens ni documentación sensible en su primer mensaje.

Alojamiento de esta página

Esta página está alojada en GitHub Pages. No añadimos formularios, publicidad ni scripts de analítica. GitHub registra direcciones IP de visitantes para fines de seguridad según su documentación. Consulte la política de privacidad de GitHub.

Cambios

Actualizaremos este documento si cambia el tratamiento de datos. La fecha de esta página identifica su versión. Para consultas contacte al responsable.
